IntroDB.app v4.2.2 Universal

Complemento de sincronización y generación de marcadores multimedia para Emby Server. Integra la base de datos comunitaria de IntroDB.app para automatizar la inserción de capítulos nativos (intros, resúmenes, créditos finales y escenas post-créditos), permitiendo el salto de secuencias tanto en clientes nativos de Emby como en reproductores externos (Infuse, Nuvio y Kodi).

Estrategia de Operación

Prioriza la sincronización con IntroDB.app. Los elementos sin registros en el proveedor principal conservan los marcadores provistos por TheIntroDB u orígenes locales.

Estado Maestro y Automatización en Tiempo Real

Interruptor maestro del complemento. Si se desactiva, se suspenden de inmediato todas las consultas a la API de IntroDB, las tareas programadas y la detección en tiempo real, manteniendo guardadas las credenciales y métricas.
Cuando se incorpora un nuevo episodio o película a la biblioteca, IntroDB procesa los identificadores e inyecta los capítulos de forma inmediata.
Si un elemento se reproduce antes de ser indexado por el escaneo general, consulta IntroDB al vuelo para garantizar el salto inmediato.

Tipos de Segmentos Multimedia

Registra el intervalo de apertura permitiendo el salto de intro en Emby, Infuse, Nuvio y navegadores.
Localiza el inicio de los créditos para omitir canciones de cierre y activar la sugerencia de siguiente episodio.
Rastrea marcas de inicio de créditos finales y post-créditos en largometrajes.
Agrega un marcador de capítulo hacia la escena tras los créditos cuando esté registrada en la base de datos.

Integración con IntroDB.app

Las consultas de lectura y descarga de marcas son públicas y no requieren clave. La clave de API es personal y opcional; se utiliza para enviar aportes validados a la comunidad.

ℹ️ Información sobre la Indexación y Caché:

  • Escaneo Periódico: Proceso automatizado en segundo plano que consulta IntroDB para asociar marcas de tiempo a cada elemento de la colección.
  • Caché 404 (Sin registros): Los títulos sin marcas en IntroDB se indexan temporalmente en caché local para evitar saturar la API con consultas reiterativas infructuosas.
  • Actualización: Si has subido nuevos timestamps a la plataforma o agregado contenido reciente, presiona "Limpiar Caché de No Encontrados (404)" en la pestaña de Herramientas para permitir una nueva consulta inmediata.
